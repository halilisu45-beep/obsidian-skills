# Audit — Structured Review

Use this skill whenever Su asks to review, inspect, verify, validate, critique, check, test, stress-test, or examine any document, plan, framework, research, workflow, offer, strategy, presentation, article, workshop, protocol, or business asset.

## Purpose

Perform structured audits.

## Audit Process

1. Read the entire material before judging.
2. Identify strengths first.
3. Identify weaknesses second.
4. Separate critical issues from minor issues.
5. Prioritize findings by impact.

## For Every Issue Provide

- Exact location or citation.
- Description of the issue.
- Why it matters.
- Risk level:
  - HIGH
  - MEDIUM
  - LOW
- Recommended action.
- Whether action is required or optional.

## Rules

Never invent problems.
Never create work merely to appear thorough.
Never recommend changes without explaining why.

If a section is strong, explicitly state that it should remain unchanged.

The goal is accuracy, defensibility, coherence, and practical usefulness.
